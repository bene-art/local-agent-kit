# Security Policy

## Reporting a vulnerability

If you've found a security issue — leaked credential in this repo's history, vulnerable dependency, exploitable bug — **please don't open a public issue**.

Use GitHub's private vulnerability reporting: go to the [**Security** tab](https://github.com/bene-art/local-agent-kit/security/advisories/new) and click **Report a vulnerability**.

Solo maintainer — best-effort response within a week, no formal SLA.

## Supported versions

Only the latest commit on `main` is supported. Tagged releases on PyPI are snapshots; security fixes ship on `main` and the next release, not as backports.
